## 2. 주요 학습 내용 정리

### 🖥️ 서버 운영 및 가상화 기술 비교
1. **베어메탈 (Bare Metal)**
   - 물리적 하드웨어 위에 OS를 직접 설치하여 운영
   - **장점**: 구조가 단순하며 성능이 매우 우수함
   - **단점**: 격리성이 약하여 리소스 독점이나 보안 위험에 취약함
2. **하이퍼바이저 가상화 (Hypervisor / VM)**
   - 호스트 OS 위에서 하이퍼바이저를 통해 여러 게스트 OS(VM)를 실행
   - **장점**: 강한 격리 환경 제공
   - **단점**: 각 VM마다 별도의 게스트 OS 커널이 필요하여 오버헤드가 큼
3. **컨테이너 가상화 (Container)**
   - 별도의 게스트 OS 없이 호스트 OS 커널을 공유하며 애플리케이션 실행 환경을 격리
   - **핵심 기술**: 네임스페이스(Namespace: 공간 격리), cgroups(리소스 사용량 제어)
   - **장점**: 매우 가볍고 시작 속도가 빠르며 배포 및 운용이 용이함

---

### 🐧 리눅스 환경 구축 (WSL2 / Ubuntu)
- **WSL2 (Windows Subsystem for Linux 2)**: 윈도우 환경에서 리눅스 커널을 가상화하여 효율적으로 리눅스를 실행하는 기술
- **주요 설정 명령어**:
  - `wsl -l -v`: 설치된 리눅스 배포판 및 상태/버전 확인
  - `wsl --install -d Ubuntu-24.04`: 특정 우분투 배포판 설치
  - `wsl --set-default Ubuntu-24.04`: 기본 배포판 지정

### 💻 리눅스 기본 명령어 정리

#### 1) 디렉터리 및 파일 조작
- `pwd`: 현재 작업 중인 경로 출력
- `ls -la`: 숨김 파일 포함, 파일 상세 정보(권한, 크기, 수정일 등) 확인
- `mkdir <폴더명>` / `rmdir <폴더명>`: 디렉터리 생성 및 빈 디렉터리 삭제
- `touch <파일명>`: 빈 파일 생성
- `cat <파일명>`: 파일 내용 전체 출력
- `cp <원본> <복사본>` / `mv <원본> <이동/변경>`: 파일 복사 및 이동/이름 변경
- `rm <파일명>`: 파일 삭제

#### 2) 권한 관리 (`chmod`)
- 권한 구조: `r(4)` - 읽기 / `w(2)` - 쓰기 / `x(1)` - 실행
- `chmod 755 <파일명>`: 소유자(`rwx`: 7), 그룹(`r-x`: 5), 기타 사용자(`r-x`: 5) 권한 부여

#### 3) 기타 및 유용한 명령어
- `echo "text" > file.txt`: 파일 덮어쓰기 (새 내용 작성)
- `echo "text" >> file.txt`: 파일에 내용 추가하기
- `history`: 이전 실행 명령어 목록 조회
- `!!`: 직전 실행한 명령어 재실행 (예: `sudo !!`)
- `!103`: history 상 103번째 명령어 실행
- `tail -f <로그파일명>`: 파일의 마지막 부분을 실시간 추적하여 모니터링

### 🐙 Git & GitHub 기초

#### 1) Git 기본 사용법
- `git init`: 현재 디렉터리를 Git 로컬 저장소로 초기화
- `git status`: 현재 저장소 상태(Staging Area 상태, 변경된 파일 등) 확인
- `git add <파일명>`: 커밋에 포함할 변경사항 선택 (Staging Area 추가)
- `git commit -m "메시지"`: 준비된 변경사항을 하나의 버전(스냅샷)으로 기록
- `git log --oneline`: 커밋 이력을 한 줄씩 간결하게 조회
- `git switch -c <브랜치명>`: 새로운 브랜치 생성 및 이동
- `git diff <커밋1> <커밋2>`: 두 커밋 간의 변경 내용 비교

#### 2) GitHub CLI (`gh`) 연동
- `gh auth login`: CLI를 통한 GitHub 계정 인증 로그인
- `gh repo create <레포이름> --public --source=. --remote origin --push`: 
  현재 디렉터리를 원격 저장소로 지정하여 GitHub에 생성 및 첫 푸시
- `git push`: 로컬 저장소의 커밋을 원격 저장소로 업로드
- `gh auth logout`: 공용 PC 이용 시 계정 인증 정보 로그아웃
