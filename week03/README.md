# 3주차: 셸 스크립팅과 로컬 AI 서비스 자동화

## 1. 개요 및 학습 목표
- 반복적인 시스템 작업 자동화를 위한 셸 스크립트(Shell Script) 작성 능력 습득
- 셸 스크립트의 실행 권한, Shebang, 파일 경로 처리 방식 및 조건문 구조 이해
- 환경 변수(Environment Variables)를 활용한 애플리케이션 실행 환경 제어
- Ollama 및 Qwen 대형 언어 모델(LLM) 기반의 로컬 AI 서비스 구성

---

## 2. 주요 학습 내용 정리

### Ollama & Qwen 모델 기반 로컬 AI 서비스
1. **Qwen (대형 언어 모델)**
   - 알리바바 클라우드에서 개발한 오픈소스 대규모 언어 모델(LLM)
   - **매개변수(Parameter)와 $B$의 의미**:
     - 모델 이름 뒤의 $B$는 Billion(10억 개)을 의미하며, 학습된 파라미터 개수(뇌의 크기)를 뜻함
     - 예: `qwen3:0.6b` (약 6억 개), `qwen3:1.7b` (약 17억 개), `qwen3:8b` (약 80억 개)
     - 파라미터가 클수록 언어 패턴 및 문법 표현 능력이 향상되나, 연산량과 메모리 사용량이 증가함
2. **Ollama (로컬 LLM 실행 플랫폼)**
   - 로컬 환경에서 대규모 언어 모델을 간편하게 설치, 관리, 실행할 수 있게 해주는 오픈소스 서비스
   - 기본적으로 REST API 포트(`127.0.0.1:11434`)를 통해 모델 추론 기능 제공
3. **로컬 AI 서비스 아키텍처**
   - **클라이언트 (웹 브라우저)**: 사용자 질문 전달 및 응답 화면 표시
   - **파이썬 웹 앱 (`chat.py`)**: 사용자 요청을 수신하여 Ollama API로 전달
   - **Ollama 서버**: 로컬 백엔드에서 지정된 Qwen 모델을 구동하여 텍스트 생성

### 🐚 셸 스크립트 핵심 개념 및 구조
1. **자동화의 필요성**
   - 반복적인 로그 백업, 파일 정리, 서비스 실행 등의 작업을 스크립트화하여 human error 방지 및 작업 시간 단축
2. **Shebang (`#!`)**
   - 스크립트 파일의 첫 줄에 위치하여 해당 파일이 어떤 인터프리터로 해석 및 실행되어야 하는지 OS에 전달하는 선언문
   - 예: `#!/bin/bash` (Bash 셸로 실행), `#!/usr/bin/env python3` (파이썬 환경으로 실행)
3. **안전한 실행 경로 제어**
   - `$(dirname "$0")`: 실행 중인 스크립트 파일이 위치한 디렉터리 경로 추출
   - `cd "$(dirname "$0")" || exit 1`: 스크립트가 어디서 호출되든 파일이 존재하는 위치로 경로를 이동하고, 실패 시 실패 코드(`1`)로 종료하여 안전성 확보
4. **명령어 치환 및 종료 상태 코드 (Exit Status)**
   - **명령어 치환 `$(...)`**: 괄호 내부 명령어의 표준 출력을 해당 위치에 치환
   - **종료 상태 코드 ($?$)**: 실행 직후 명령의 성패 반환. 성공은 `0`, 실패는 `0 이외의 값(예: 1)`을 나타냄
5. **`exec` 명령어의 역할**
   - 별도의 자식 프로세스를 생성하지 않고, 현재 구동 중인 셸 프로세스(PID)를 실행하려는 프로그램 프로세스로 교체하여 리소스 오버헤드 절감

### ⚙️ 환경 변수 및 조건문을 통한 실행 환경 검증
1. **환경 변수 전달 (`export`)**
   - 자식 프로세스 및 외부 프로그램으로 변수 설정을 전달하기 위해 `export` 키워드 사용
   - 스크립트 내 지정된 변수 설정(예: `MODEL`, `WEB_PORT`)은 해당 스크립트의 실행 범위 내에서만 유효하며 원본 터미널 환경에 영향을 주지 않음
2. **Here Document (`<< 'EOF'`)**
   - 스크립트 내에서 여러 줄의 문자열을 지정된 구분자(EOF 등)를 기준으로 파일에 작성하는 기법
   - 구분자에 따옴표(`'EOF'`)를 씌우면 내부 변수가 변환되지 않고 원본 문장 그대로 저장됨
3. **조건문을 이용한 사전 점검 (친절한 스크립트 만들기)**
   - **`command -v <명령어>`**: 해당 명령어가 시스템 경로(PATH)에 존재하고 실행 가능한지 확인
   - **리다이렉션 기법**:
     - `>/dev/null`: 표준 출력(stdout) 버림
     - `2>&1`: 표준 오류(stderr)를 표준 출력과 동일한 위치로 보냄
   - 필수 실행 환경(예: Python3 설치 여부)을 점검하고 미설치 시 가이드 메시지 출력 후 종료(`exit 1`)하는 예외 처리 방식을 적용

  - 파일 실행 권한(`chmod u+x`) 부여 및 스크립트 실행 제어

  - 환경 변수 전달 방식으로 포트 및 구동 모델을 동적으로 변경하는 스크립트 모듈화
